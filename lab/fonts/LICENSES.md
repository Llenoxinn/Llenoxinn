# Font licenses

Every profile font is released under the SIL Open Font License 1.1; the license text accompanies each family.

| Files | Family | Usage / source |
|---|---|---|
| `BlackOpsOne-Regular.ttf` | Black Ops One | Chrome titles. [Google Fonts](https://github.com/google/fonts/tree/main/ofl/blackopsone). `OFL-BlackOpsOne.txt` |
| `RussoOne-Regular.ttf` | Russo One | Headings, banners, buttons. [Google Fonts](https://github.com/google/fonts/tree/main/ofl/russoone). `OFL-RussoOne.txt` |
| `BarlowCondensed-Medium/SemiBold/Bold.ttf` | Barlow Condensed | Text and labels. [Google Fonts](https://github.com/google/fonts/tree/main/ofl/barlowcondensed). `OFL-BarlowCondensed.txt` |
| `Teko-SemiBold.ttf` | Teko | Numbers; a static weight-600 instance cut with fontTools from the variable font. [Google Fonts](https://github.com/google/fonts/tree/main/ofl/teko). `OFL-Teko.txt` |

Icons in `lab/icons.py` come from Simple Icons 13.21.0 and 16.38.0 (CC0 1.0), Devicon 2.17.0 (MIT) and Phosphor Icons 2.1.1 (MIT). Project logos in `lab/data/logos/` are the projects' own favicons.
